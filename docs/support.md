# Support path

For account, ingestion, retrieval, or security issues, email `support@knowledgeforge.ai`
with:

- The request ID from the `X-Request-ID` response header
- The affected endpoint and approximate UTC time
- The document ID, if applicable
- A description that excludes passwords, tokens, API keys, and confidential document text

Security vulnerabilities should be marked `SECURITY` in the subject line. Do not send
credentials or raw uploaded documents by email.
